Icons — replacing emoji Fix

The app currently uses emoji for icons — ⚡ 🕐 📍 🗣 ⭐ 🔄. They render differently on every platform, cannot take brand colour, and read as unfinished. This set is stroke-based on a 24px grid at 1.8, so it scales and recolours.

What this pass changes, and why
1 Emoji became icons

Every glyph in the product is now a stroke SVG that takes brand colour and renders the same on a Pixel and an iPhone.

2 A type scale with a top

Nothing in the app was larger than 16.8px, so every screen read at one volume. Display sizes give each page one thing that leads.

3 Price differences shown

Dynamic pricing already computes an off-peak discount. It was invisible. Now €52-against-€65 is on the card, the slot and the rail.

4 Services stopped being a list

A €189 balayage and a €39 blow-dry were the same object. The signature service now gets a card; the rest stay compact rows.

5 Empty time became a target

On the operator calendar every free half-hour is a dashed add-slot, so booking a walk-in never means hunting for a toolbar button.

6 Seven tabs became a spine

A top tab bar is a customer-app pattern. A tool open eight hours a day wants a persistent sidebar with room for live counts.
