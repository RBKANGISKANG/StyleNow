# StyleNow ✦

**Your personal stylist, right now.** An interactive fashion app for discovering looks, building outfits, and finding your style persona.

## Features

- **🏠 Discover** — a curated feed of 12 editorial looks, filterable by vibe (Minimal, Chic, Street, Boho, Sporty, Classic) and occasion, with live search. Tap any look for the full piece list and styling note; tap the heart to save it.
- **🎨 Outfit Builder** — mix and match tops, bottoms, shoes, layers, and accessories with arrow controls or the "Surprise me" shuffle. A live **style-match score** tells you how well your pieces speak the same language. Name and save your favorite combinations.
- **🔮 Style Quiz** — a five-question quiz that reveals your style persona (Minimalist, Modern Romantic, Trendsetter, Free Spirit, Athleisurist, or Timeless One) and unlocks a personalized "Picked for you" row on the home feed.
- **👗 My Wardrobe** — a digital closet. Add pieces with a name, color, category, and icon; filter by category; remove items you've retired.
- **❤️ Saved** — everything you've hearted plus every outfit you've built, in one place.

Light & dark themes, smooth animations throughout, fully responsive, and everything persists locally in your browser — no account needed.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

Built with React + Vite. No backend required.
